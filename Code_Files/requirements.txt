# Day Shift - requirements
#
# This is a JavaScript (Node.js) web app, not a Python project, so there is nothing to
# `pip install`. The npm packages below are installed automatically from package.json by
#     cd Code_Files
#     npm install
# The versions are the ones the prototype was built and tested with (see package-lock.json).

# ---- System ----
Node.js >= 18          # tested with Node 24.20, npm 11.19
npm >= 9               # comes with Node.js
Google Chrome or Microsoft Edge (recent)   # voice commands need Chrome/Edge; the rest also runs in Firefox
Webcam                 # built-in laptop camera is enough
Internet               # only for `npm install` and for voice commands; the game itself runs offline
